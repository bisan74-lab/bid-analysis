# bid-analysis

(주)케이알에스건설의 면허·실적·신용등급을 기준으로 토목공사 입찰가(낙찰 확률이 높은 투찰가)를 분석하는 프로젝트.

## 폴더 구성

- `CLAUDE.md` — 프로젝트 배경, 회사 정보, 제약사항 (Claude Code가 매 세션 참고)
- `PROGRESS.md` — 세션별 작업 기록
- `data/company-profile.md` — 확인서 원문 데이터 정리
- `data/license-capacity.csv` — 면허(업종)별 시공능력평가액 등 분류표
- `credentials.local.md` — 아이건설넷 로그인 정보 (git 미포함)
